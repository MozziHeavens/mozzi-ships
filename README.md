# Mozzi Ships 🚢

Lanzador e instalador estilo N64 + Frutiger Aero para los ships de Harbour Masters en Android.

**Hecho por Mozzi y Claude (y un Dodo revivido) 🦤**

- Instala los ships incluidos (sin ROMs: cada ship te pide la tuya).
- Detecta si tu teléfono es de 32 o 64 bits y solo ofrece los compatibles.
- Música original del menú por Mozzi.
